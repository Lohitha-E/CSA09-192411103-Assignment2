# Q1 – Screenshots

**Task:** Railway e-ticket text building (+ / StringBuilder / StringBuffer)

## How to capture

1. Open `Q1/Main.java` in VS Code (the source code must be visible in the editor).
2. Open the integrated terminal (Terminal → New Terminal) and run:
   ```bash
   cd Q1
   javac Main.java
   java Main
   ```
3. Take a **genuine** screenshot showing the source code in the editor **and** the execution output in the terminal. Do not edit or fabricate screenshots.
4. If the output is longer than the terminal window, take one screenshot per case below (scroll the terminal).

## Cases to capture

- [ ] Case 1 – Workload A: short ticket (10 fields) x 200000  →  save as `case1.png`
- [ ] Case 2 – Workload B: 10000 tickets x 50 fields  →  save as `case2.png`
- [ ] Case 3 – Workload C: 20 very long tickets x 3000 fields  →  save as `case3.png`
- [ ] Case 4 – Shared booking log, 8 threads x 200000 appends (cores=1)  →  save as `case4.png`

Also save one full-run capture as `../OUTPUT.PNG`.


## Notes

Timing values vary from run to run and machine to machine; use the values from **your own** run in the report.
